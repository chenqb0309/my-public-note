# 學習資源：專項面試輔導

> 課程 Area 4 — 這不是知識，是應試準備。在你開始投履歷前 2-4 週再細讀。

---

## RAG 面試常見問題

課程列出的題目，你可以先思考答案：

1. **大模型應用開發的三種主要模式？**
   - 提示工程、RAG、微調 — 三種的適用場景與取捨

2. **文檔分塊策略及理由？**
   - 固定長度 vs 語義分塊 vs 遞迴拆分
   - 為什麼某些場景要 parent document retriever

3. **RAG 系統架構圖？**
   - 能在白板上畫出完整 pipeline：Document → Chunk → Embed → Store → Retrieve → Rerank → Generate

4. **Embedding 模型選型理由？**
   - MTEB 榜單、維度取捨、開源 vs 商業

5. **RAG 效果調試維度？**
   - 資料品質、chunk 策略、檢索召回率、rerank、prompt 指令

6. **混合檢索特點？**
   - BM25（關鍵詞）+ 向量檢索（語義）的互補

7. **RAG 評估指標？**
   - Faithfulness、Answer Relevance、Context Precision、Recall

## 面試準備策略

1. **技術問題**：用 STAR 原則回答，把你的實際專案（InboundHandling、Hermes Agent）套進去
2. **系統設計**：準備一個 RAG 系統設計、一個 Agent 系統設計
3. **程式題**：很少考白板題，多數是問 design decision
4. **你的獨特賣點**：
   - 跨領域（品保/生產 → 業務 → 軟體 → AI）
   - 有拿到真實產品落地的經驗
   - 有 AI Agent 協作流程的設計實戰

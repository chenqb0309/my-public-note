## LLM 微調原理

### 高效微調方法
- **全參數微調（Full Fine-tuning）**：所有權重都更新 — 效果好但貴
- **PEFT（Parameter Efficient Fine-Tuning）**：只更新少量參數

### LoRA（Low-Rank Adaptation）
https://arxiv.org/abs/2106.09685

**核心概念**：
```
原始權重 W 是固定的
新增一個低秩矩陣 ΔW = A × B（A 小、B 小）
訓練時只更新 A 和 B
推論時可以合併回 W（不增加推理成本）
```

白話：**你不改整個模型，而是在旁邊加一個小模組專門學你的任務**。

### QLoRA
LoRA + 4-bit 量化，讓你可以在一張消費級顯卡上微調 7B 模型。

## 微調資料工程

這其實是微調最花時間的部分（遠超過訓練本身）：

| 步驟 | 重要性 | 說明 |
|------|--------|------|
| 資料收集 | 🔴 高 | 需要高品質的指令-回覆對 |
| 資料清洗 | 🔴 高 | 重複、錯誤、偏見資料的過濾 |
| 格式標準化 | 🟡 中 | ShareGPT / Alpaca 格式 |
| 品質評估 | 🔴 高 | Garbage In, Garbage Out |

### SFT vs RLHF
- **SFT（Supervised Fine-Tuning）**：用正確答案教模型
- **RLHF（Reinforcement Learning from Human Feedback）**：讓人類偏好引導模型行為

---

## 模型蒸餾（Model Distillation）

用一個大模型（Teacher）的知識去訓練一個小模型（Student）。

- 目的：保留大模型的能力，但體積更小、速度更快
- 課程實作：使用 unsloth 框架進行蒸餾

## 建議學習順序

📘 **完整學習課表**：[[自學課表-16週計畫]]（含每週進度、連結、時數、Checkpoint）

```
階段 1（第 1-3 週）：
  Python 速通（C00） + 挑一個 RAG 教學跑通（C05）

階段 2（第 4-8 週）：
  LangChain/LlamaIndex（C01） + 做一個你 MES 領域的 RAG 作品（C03-1）

階段 3（第 9-12 週）：
  Agent 理論 + MCP + Harness（C06） + 對比你的 Hermes 設計

階段 4（第 13-16 週）：
  面試準備（C04） + 部署實戰（C09） + 補缺口
```

> 這份順序假設你每週投入 8-10 小時（下班後 1-2 小時 + 週末半天）。
> 如果全職投入，時間可壓縮到 6-8 週。

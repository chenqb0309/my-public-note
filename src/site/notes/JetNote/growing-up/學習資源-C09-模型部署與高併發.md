## 高併發原理（面試加分題）

### KV Cache
Transformer 推理時，每個 token 的計算會產生 Key 和 Value 矩陣。
KV Cache 就是把這些快取起來，避免重複計算。

**瓶頸**：KV Cache 佔用大量記憶體（尤其是長 context）。

### PagedAttention（vLLM 核心技術）
https://arxiv.org/abs/2309.06180

- 作業系統的分頁（Paging）概念應用在 KV Cache
- 不像傳統方式需要連續記憶體，PagedAttention 可以把 KV Cache 放在不連續的頁面中
- **效果**：記憶體利用率提升 2-4 倍

### Continuous Batching
- 傳統：等一個請求完全生成完，才處理下一個
- Continuous Batching：在同一個批次中，動態加入/移除請求
- **效果**：吞吐量提升 10-20 倍

## SGLang 深度優化

### Radix Tree
- 把 prompt 的前綴（system prompt、few-shot 範例）建立成基數樹
- 相同的 prompt 前綴可以共享 KV Cache
- **效果**：多使用者共用相同 system prompt 時，記憶體大幅降低

### Token Healing
- 當 prompt 的 tokenization 邊界不理想時，自動修正
- 提升生成品質

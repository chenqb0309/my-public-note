# 學習資源：項目實戰

> 課程 Area 3 — 這是最有價值的部分，全部是真實落地案例。
> **建議策略**：先讀你有直接關聯的（Hermes、RAG），再讀工業相關的（AI質檢），其他了解即可。

---

## 1. 企業知識庫（RAG 大賽冠軍方案）

這是最完整的 RAG 落地案例，適合當作你的 side project 範本。

### 課程涵蓋
- RAG 冠軍方案：多路由 + 動態知識庫
- 完整 pipeline：解析 → Docling → 內容提取 → 檢索 → Rerank → 生成
- 父頁面檢索（Parent Retriever）
- 指令細化（Instruction Refinement）
- Prompt 模組化實作（Prompt.py）

### 你的練習方向
把你 InboundHandling 的文件（spec、README、程式碼註解）當作知識庫來源，
用課程學到的冠軍方案實作一個「MES 知識庫 RAG」。

---

## 2. OpenManus 開發實戰

### 課程核心
- OpenManus 框架深度解析：Orchestrator → Agents → Memory → Tools
- 角色定制 Agents
- 整合企業知識庫 RAG
- 中文寫作流

### 為什麼對你有價值
OpenManus 的架構跟你目前 Hermes Agent 的 Offer/Corer/Taster/Auditor 模式非常接近：
```
Orchestrator（Offer） → 拆任務
Agents（Corer + Taster） → 執行
Memory → 記憶層
Tools → 工具鏈
```

### 參考
https://github.com/microsoft/OpenManus

## 3. AI 質檢（YOLO vs Qwen-VL）

### 課程案例
- 數據集 EDA（缺陷類別、圖像特點）
- YOLO 訓練與調優
- Qwen-VL 多模態大模型零樣本缺陷檢測
- 兩種方案的對比分析

### 你的切入點
- 如果你們公司或客戶有視覺檢測需求，這會是很有價值的參考
- 如果沒有，**只需閱讀了解即可**，跳過實作

## 4. Hermes Agent 長期記憶與自進化能力

### 課程核心
- 心跳喚醒機制 + 自適應頻率調整
- 4 層記憶顆粒度：Tier0 → Tier1 → Tier2 → Tier3
- LanceDB + Embedding 混合檢索
- 意圖識別與記憶路由

### 這跟你直接相關
你在用 Hermes Agent，這正是它的底層機制。
課程幫你補齊「為什麼這樣設計」的理論依據。

---

## 5. Hermes 多 Agent 協作與主 Agent 調度

### 課程核心
- 主 Agent：意圖理解 → 任務拆解 → 智能分發 → 權限管控
- 子 Agent：標準結構 → 註冊機制 → 執行流程
- Agent 間通信 + 任務依賴 + 異常處理
- 全局閉環：結果回收 → 狀態同步 → 自進化底座

### 對你的意義
你已經在用這個模式。課程讓你用別人的系統來驗證你的設計是否合理。
